# Resonate documentation experiment

A static Astro + Starlight landing page and quickstart for the `/resonate/` GitHub Pages project path. There is no deployment workflow in this experiment. Guides not yet ported link to the current documentation site.

From this directory, using Node.js 24.22.3 or later:

```sh
npm ci
npm run build
npm run preview
```

Open `/resonate/`. Search is indexed during the production build; use the preview to check it. Open the quickstart, change the SDK in one section, then check the worker command and output. The quickstart text, code examples, and banners are adapted from [`resonatehq/docs.resonatehq.io` at `46596c4`](https://github.com/resonatehq/docs.resonatehq.io/tree/46596c4), under Apache-2.0. This experiment does not run the SDK examples.
