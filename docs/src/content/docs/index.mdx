## A function. Not a flowchart.

Keep the loops and branches you already know. Wrap a step to record its result. Use a durable sleep between ticks.

<Tabs>
<TabItem label="TypeScript">

```typescript title="Inside countdown.ts"
for (let i = count; i > 0; i--) {
  yield* context.run((context: Context) => console.log(`Countdown: ${i}`));
  yield* context.sleep(delay * 1000);
}
```

</TabItem>
<TabItem label="Python">

```python title="Inside countdown.py"
for i in range(count, 0, -1):
    await ctx.run(ntfy, i)
    await ctx.sleep(timedelta(seconds=delay))
```

</TabItem>
